# Esp.rf.443
 RF 433MHz + IR + WiFi Controller with

## A2 Plytka (PCB Board)

The **A2** is the current PCB board revision for the Esp.rf.443 project.

### Board Features

- ESP8266/ESP32 Wi-Fi module
- RF 433MHz transmitter/receiver
- IR transmitter/receiver
- Onboard power regulation

### Delivery Information

The A2 Plytka is available for delivery. To order a board:

1. Open an issue in this repository with the subject `[ORDER] A2 Plytka`
2. Provide your shipping address and quantity
3. You will receive a confirmation with estimated delivery time

### Board Pinout

| Pin | Function         |
|-----|------------------|
| D1  | RF 433MHz TX     |
| D2  | RF 433MHz RX     |
| D3  | IR TX            |
| D4  | IR RX            |
| 3V3 | Power (3.3V)     |
| GND | Ground           |
